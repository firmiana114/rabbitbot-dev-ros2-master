# Ubuntu系统音频流式录制使用说明

## 概述

本项目提供了两个Python脚本来实现Ubuntu系统中的音频流式录制功能：

1. `stream_audio_recorder.py` - 功能完整的高级音频录制器
2. `simple_audio_recorder.py` - 简单易用的基础音频录制器

## 安装依赖

### 自动安装
运行提供的安装脚本：
```bash
chmod +x setup_audio_recording.sh
./setup_audio_recording.sh
```

### 手动安装
```bash
# 安装系统依赖
sudo apt update
sudo apt install pulseaudio pulseaudio-utils alsa-utils portaudio19-dev python3-dev python3-pip

# 安装Python依赖
pip3 install pyaudio wave numpy sounddevice
```

## 使用方法

### 1. 简单音频录制器 (simple_audio_recorder.py)

适合快速录制音频的场景。

#### 交互式运行
```bash
python3 simple_audio_recorder.py
```

#### 程序化调用
```python
from simple_audio_recorder import record_audio

# 录制10秒音频
record_audio(duration=10, filename="my_recording.wav")
```

### 2. 高级音频录制器 (stream_audio_recorder.py)

提供更多功能和配置选项。

#### 基础用法

```bash
# 录制10秒音频
python3 stream_audio_recorder.py --duration 10

# 指定输出文件名
python3 stream_audio_recorder.py --duration 15 --output "meeting_record.wav"

# 手动停止录制 (Ctrl+C)
python3 stream_audio_recorder.py
```

#### 高级功能

```bash
# 列出所有音频设备
python3 stream_audio_recorder.py --list-devices

# 实时监控模式（显示音量电平）
python3 stream_audio_recorder.py --monitor --duration 30

# 自定义音频参数
python3 stream_audio_recorder.py --sample-rate 48000 --channels 1 --duration 20
```

#### 程序化使用

```python
from stream_audio_recorder import StreamAudioRecorder

# 创建录制器实例
recorder = StreamAudioRecorder(
    output_dir="./recordings",
    sample_rate=44100,
    channels=2
)

# 列出音频设备
recorder.list_audio_devices()

# 开始录制
recorder.start_recording(duration=10, filename="test.wav")

# 带监控的录制
recorder.record_with_realtime_monitoring(duration=15)

# 清理资源
recorder.cleanup()
```

## 音频参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| sample_rate | 44100 | 采样率(Hz)，CD音质 |
| channels | 2 | 声道数，1=单声道，2=立体声 |
| chunk_size | 1024 | 音频缓冲区大小 |
| format | paInt16 | 音频格式，16位整数 |

## 输出文件格式

- 格式：WAV (无压缩)
- 编码：PCM
- 位深：16位
- 默认文件名：`audio_recording_YYYYMMDD_HHMMSS.wav`

## 故障排除

### 常见问题

1. **权限错误**
   ```bash
   # 将用户添加到audio组
   sudo usermod -a -G audio $USER
   # 重新登录或运行
   newgrp audio
   ```

2. **找不到音频设备**
   ```bash
   # 检查音频系统状态
   pulseaudio --check -v
   
   # 重启音频系统
   pulseaudio -k
   pulseaudio --start
   ```

3. **PyAudio安装失败**
   ```bash
   # 安装开发依赖
   sudo apt install portaudio19-dev python3-dev
   pip3 install --upgrade pyaudio
   ```

4. **音频质量问题**
   - 增加采样率：`--sample-rate 48000`
   - 减少缓冲区大小以降低延迟
   - 使用单声道减少文件大小：`--channels 1`

### 调试命令

```bash
# 检查音频设备
aplay -l        # 播放设备
arecord -l      # 录制设备

# 测试录制
arecord -f cd -t wav -d 5 test.wav

# 检查PulseAudio
pactl list sources short
pactl list sinks short
```

## 性能优化

- **低延迟录制**：减少chunk_size
- **高质量录制**：增加sample_rate
- **节省存储空间**：使用单声道 + 较低采样率
- **长时间录制**：定期保存临时文件
