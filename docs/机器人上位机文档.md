
## Q1：如何查询上位机 IP？

开机之后，连显示器和键盘，Ctrl + Alt +T 打开终端，输入 `ifconfig`，看到 `10.10.30.xx` 为上位机的 IP

## Q2：如何查询 MSRA Jetson IP？

在上位机终端，输入连接进 MSRA Jetson

```shell
ssh jianyu@192.168.26.13
```

然后再

```shell
ifconfig
```

即可看到 MSRA Jetson IP

## Q3：如何查询下位机 IP？

在上位机终端，输入连接进下位机

```shell
ssh lab@192.168.26.12
```

密码是三个空格

然后再

```shell
ifconfig
```

即可看到下位机 IP
