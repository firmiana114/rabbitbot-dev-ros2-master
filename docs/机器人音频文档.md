
## 1. 查看音频设备

```shell
docker exec -it navid-vllm-cuda-mic /bin/bash -c "cd /datanvme/fuchengjia/projects/rabbitbot-dev-ros2-dev && bash scripts/start_pyaudio_test.bash"
```

```shell

# USB Composite Device 麦克风，对应 STT
25: USB Composite Device: Audio (hw:3,0) (host API: 0, max input channels: 1)
```

## 2. 设置音频设备

在 `scripts/start_stt_app.bash` 中，修改设备编号

```shell
# 对应 USB Composite Device
export INPUT_DEVICE_INDEX=25
```

在 `scripts/start_tts_app.bash` 中，修改设备编号

```shell
# 对应 CS201
export OUTPUT_DEVICE_INDEX=4
```

## 3. 设置音响的音量

3.1 查询音响设备（在 Docker 外面）

```shell
pactl list short sinks | grep "CS201"
```

3.2 看到下面输出，得知序号是 0

```shell
0       alsa_output.usb-Generic_CS201_20210726905926-00.analog-stereo   module-alsa-card.c      s16le 2ch 48000Hz       SUSPENDED
```

3.3 设置音量（在 Docker 外面）

```shell
pactl set-sink-volume 0 90%
```
