
## 启动 VLM 和 YOLO

1. 启动 VLM

```shell
docker start vlm_v1
docker exec -d vlm_v1 /bin/bash /data/start_vllm.sh
```

2. 启动 YOLO

```shell
docker start yolo
docker exec -d yolo /bin/bash /datanvme/fuchengjia/projects/rabbitbot-dev-ros2-dev/scripts/start_yolo_app.bash
```
