### 1.1 在边缘台式机启动三个 Apps

conda activate sound

## 2 - 机器人控制模块

第 2 部分都是在 MSRA Jetson 上

### 2.0 确认 kuavo_configs.json

```shell
/datanvme/fuchengjia/projects/rabbitbot-dev-ros2-dev/kuavo_configs.json
```

2.1 和 2.2 需要和钟旭他们确认后再启动。如果确认了，请把 `kuavo_configs.json` 中的 `kuavo_robot_ros` 设置为 `enable`，否则为 `disable`。

2.3 需要设置 `kuavo_configs.json` 中的 `kuavo_robot_camera`，正常是 `genimi`，但是如果不需要，可以改成 `null`。

### 2.1 ROS 桥接

保证 `/etc/hosts` 里面有

```shell
192.168.26.12 kuavo_master
```

然后再启动 ROS 桥接

```shell
# MSRA Jetson 第三个窗口启动 ROS 桥接
docker exec -it foxy-ros-cam-orb-ubuntu20 /bin/bash -c "cd /datanvme/fuchengjia/projects/rabbitbot-dev-ros2-dev && bash scripts/start_ros_bridge.bash"
```

### 2.2 ROS Action Server

重新编译 Action

```shell
# 不要进 Docker
cd /datanvme/fuchengjia/projects/vln
git pull  # 这里需要账号密码，请钟旭和杨畅来输入

# 进 Docker
docker exec -it foxy-ros-cam-orb-ubuntu20 /bin/bash -c "cd /datanvme/fuchengjia/projects/rabbitbot-dev-ros2-dev && bash scripts/build_kuavo_action.bash"
```

启动

```shell
# MSRA Jetson 第四个窗口启动 ROS Action Server
docker exec -it foxy-ros-cam-orb-ubuntu20 /bin/bash -c "cd /datanvme/fuchengjia/projects/rabbitbot-dev-ros2-dev && bash scripts/start_kuavo_action_server.bash"
```

### 2.3 Kuavo Robot App

```shell
# MSRA Jetson 第五个窗口启动 Kuavo Robot App
docker exec -it foxy-ros-cam-orb-ubuntu20 /bin/bash -c "cd /datanvme/fuchengjia/projects/rabbitbot-dev-ros2-dev && bash scripts/start_robot_app.bash"
```

## 4 - 单独命令行测试动作

第 4 部分都是在 MSRA Jetson 上

```shell
# MSRA Jetson 新的窗口
docker exec -it foxy-ros-cam-orb-ubuntu20 /bin/bash -c "cd /datanvme/fuchengjia/projects/rabbitbot-dev-ros2-dev && bash scripts/start_kuavo_agno_tool_test.bash"
```

单独开启 ros2 命令，比如指向的动作命令（navi_ik_arm）

```shell
ros2 action send_goal /navi_ik_arm custom_action_interfaces/action/NaviIkArm \
  "{position_x: 0.5929, position_y: 0.1816, position_z: -0.319, orientation_x: 0.0, orientation_y: 0.0, orientation_z: 0.0, orientation_w: 0.0}"
```

又比如提篮子的动作命令（navi_grab）

```shell
ros2 action send_goal /navi_grab custom_action_interfaces/action/NaviGrab \
   "{position_x: 0.5929, position_y: 0.1816, position_z: -0.319, orientation_x: 0.0, orientation_y: 0.0, orientation_z: 0.0, orientation_w: 0.0}"
```

## 5 - 一些说明

Q：什么时候重启哪些 App？

* STT、TTS 一般不用重启，如果有问题再重启。
* 修改完 ros 设置后（`kuavo_robot_ros`），需要重启【2.3 Kuavo Robot App】
* 修改完 workflow.py 后，需要重启【3 workflow】
